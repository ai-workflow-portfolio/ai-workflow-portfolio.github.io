AIに任せる仕事の決め方｜4つの判断軸と職種別の仕分け一覧

2026年10月14日

目次

社員が数人から数十人の会社で、事務も採用も広報も兼ねている人は、「AIに任せる仕事」と「人がやる仕事」をどこで分ければよいか、迷うことが多いのではないでしょうか。
使ってみたい気持ちはあっても、線引きが決まらないまま、いつものやり方で作業を続けている会社は少なくありません。

この記事では、作業を分けるための判断軸と、職種ごとの仕分けの一覧を紹介します。
結論から言うと、4つの質問に順番に答えると、ほとんどの作業を「任せる・下書きまで任せる・人がやる」の3つに分けられます。

後半には、事務・経理・採用・マーケティング・営業・お客様対応の6つの職種について、よくある作業を3つに分けた一覧を載せています。
自分の会社の作業を仕分けるための指示文（プロンプト）も、全文で載せています。

よくある迷い：「何をAIに任せていいのか分からない」

少人数の会社で、仕事の流れを決める立場の人から、次のような声をよく見かけます。

  • AIが便利らしいのは分かるが、自分の会社のどの作業に使えばよいか分からない
  • 任せてみたいが、間違ったものがお客様に出てしまうのが心配
  • 社員ごとに使い方がばらばらで、会社としての決まりがない
  • 「AIか、人か」の二択で考えてしまい、結局どちらにも決められない

迷いの元は、4つ目にあることが多いです。
実際の仕事では、「全部AI」「全部人」のどちらかになる作業は多くありません。
多くなりやすいのは、AIが下書きを作り、人が確かめて出す形です。
そこで、分け方を2つではなく3つにします。

分け方中身
任せるAIが出したものを、ほぼそのまま使う。人はときどき見る
下書きまで任せるAIが作り、人が必ず読んで直してから使う
人がやる人が決める・人が話す。AIは材料の整理まで

結論：AIに任せる仕事は「4つの質問」で決められます

作業を1つ思い浮かべて、次の4つの質問に上から順に答えます。

質問答え分け方
1. 「まとめる」作業か、「決める」作業か決める人がやる
2. 材料は文字やデータでそろっていて、AIに渡してよい情報かいいえ人がやる
3. 間違えても、すぐ直せるか直しにくい下書きまで任せる
4. 毎回ほぼ同じ形の作業かいいえ下書きまで任せる
（4つとも通った作業）—任せる

質問1：「まとめる」作業か、「決める」作業か

AIは、すでにある材料を短くしたり、並べ替えたり、言い方を変えたりする作業が得意です。
一方で、採用の合否、値引き、謝り方のように、結果に責任を持つ人が必要なことは、人が決めます。

「決める」作業でも、AIが役に立たないわけではありません。
決めるための材料を整理するところまでは、AIに頼めます。

質問2：材料は文字やデータでそろっていて、AIに渡してよい情報か

AIは、渡された材料からしか作れません。
担当者の頭の中にしかない事情や、口頭でしか伝わっていない決まりは、文字にするまで使えません。

もうひとつ、渡してよい情報かどうかも、ここで確かめます。
お客様や社員の名前、連絡先、評価などは、そのままでは渡しません。
名前や連絡先を消すか置きかえても成り立つ作業は「はい」、消すと成り立たない作業（履歴書を読む、社員の評価を書く、など）は「いいえ」と答えます。
くわしくは「気をつけること」に書きました。

質問3：間違えても、すぐ直せるか

社内で使うメモなら、間違いに気づいた人がその場で直せます。
お客様に送る文、金額、契約に関わるものは、出てしまうと直しにくくなります。

直しにくいものは、AIに作らせても、人が読んでから出すと決めておきます。
これが「下書きまで任せる」です。

質問4：毎回ほぼ同じ形の作業か

会議メモの要約や、表の書き方をそろえる作業のように、毎回の形が決まっているものは、指示文を1回作れば同じ品質で繰り返せます。

毎回、相手や事情が変わる作業は、AIの出した文が合わないことがあります。
こちらも「下書きまで任せる」に入れます。

職種別：AIに任せる作業・下書きまで任せる作業・人がやる作業

ここからは、職種ごとに、よくある作業を3つに分けた一覧です。
会社によって事情は違うので、目安として使ってください。
「任せる」「下書きまで任せる」に入れた作業は、どれも、お客様や社員の名前・連絡先を消すか置きかえてから渡す前提です。

事務・総務

任せる

  • 会議の文字起こし（録音を文字にしたもの）から、社内で共有する要約と「次にやること」を作る
  • 表の列の順番や、日付・社名の書き方をそろえる
  • 長い資料や社内の決まりから、要点を抜き出す

下書きまで任せる

  • 社外に送る案内・お礼のメール
  • おわびのメール（何をどこまで謝るかを人が決めたあとの、文の形だけ）
  • 全社員に出すお知らせの文
  • 手順書やマニュアル
  • 報告書や、社内で承認をもらうための書類

人がやる

  • 契約書の中身の最終確認
  • 給与・評価・健康など、社員の個人的な情報を含む書類
  • 決まりから外れる対応を認めるかどうかの判断

経理

任せる

  • 取引先の名前や日付の書き方のばらつきをそろえる（金額の列は渡さず、名前と日付の列だけ）
  • 経理の手順メモを、順番どおりに整理し直す

下書きまで任せる

  • 請求書や見積書に添えるメールの文
  • 支払いが遅れている相手への連絡の文
  • 経費の明細を、勘定科目（経費の分類）に分ける候補を出す
  • 月ごとの数字の増減を説明する文

人がやる

  • 金額・振込先の最終確認
  • 振込や支払いの実行
  • 税金や会計の処理の判断（迷うものは税理士などの専門家に確かめる）

経理は、数字の間違いがそのままお金の間違いになります。
対話型のAI（文章で質問すると文章で答えてくれるAI）は、数字の計算や写し取りを間違えることがあるので、ほかの職種より「任せる」を少なくしています。

採用

任せる

  • 説明会や面接の日程の候補を整理する
  • 募集する仕事の内容を、社内のメモから箇条書きにする

下書きまで任せる

  • 求人票の文
  • 応募した人への連絡の文（日程の調整・お礼・結果の連絡）
  • 面接で聞く質問の案

人がやる

  • 合否の判断
  • 給与や働き方の条件の話し合い
  • 応募した人の評価

履歴書や職務経歴書は、個人の情報そのものです。
そのままAIに貼る使い方は、この一覧には入れていません。

求人票は、給与や勤務時間などの条件が実際と合っているか、年齢や性別で応募できる人をしぼる書き方になっていないかを、人が確かめてから出します。
面接の質問の案も、家族や出身地など、仕事の力と関係のないことを聞く内容になっていないかを確かめます。

マーケティング・広報

任せる

  • アンケートの自由記述を、内容ごとに分ける
  • 公開されている情報から、業界の動きの要点を整理する
  • 投稿やメールのテーマの案をたくさん出す

下書きまで任せる

  • SNSの投稿文、メールマガジン、ブログの文
  • チラシやWebページの見出しの案
  • 報道機関に送るお知らせの文

人がやる

  • 何を、だれに向けて打ち出すかの決定
  • 価格やキャンペーンの決定
  • 商品の効果や実績の書き方が、事実と合っていて、根拠を示せるかの最終確認

アンケートの自由記述を分ける手順は、アンケートの自由記述をAIで分類・集計する手順にまとめています。
名前などを消してから渡すことと、件数を表で数え直すことは、任せる場合も変えません。

営業

任せる

  • 商談のメモを要約し、「次にやること」を抜き出す
  • 訪問の前に、相手の会社が公開している情報を整理する

下書きまで任せる

  • 提案書の組み立てと、たたき台
  • 見積書に添える説明の文
  • 商談のあとのお礼のメール

人がやる

  • 見積もりの金額の決定
  • 値引きや納期の約束
  • 相手との関係づくりと、謝る場面

お客様対応

任せる

  • 届いた問い合わせを、内容の種類ごとに分ける
  • 問い合わせの記録から、よくある質問を洗い出す

下書きまで任せる

  • 問い合わせへの返信の文
  • 口コミへの返信の文
  • よくある質問のページの文

人がやる

  • 苦情を受けたときの判断と謝罪
  • 返金や交換など、決まりから外れる対応を認めるかどうか
  • 電話や対面で、お客様と直接話すこと

口コミへの返信を下書きから仕上げるまでの流れは、一人で営むサロン向けの記事ですが、サロンの口コミ返信をAIで下書きする手順で、指示文つきで紹介しています。
お店のルールを自分の会社のものに置きかえると、同じ流れで使えます。

自分の会社の作業を仕分ける指示文（プロンプト）

上の一覧に無い作業は、AIに仕分けを手伝ってもらえます。
ChatGPT や Claude などの対話型のAIに、次の指示文を貼り、最後の（　）に作業を書き出します。

あなたは、少人数の会社の仕事を整理する手伝いをします。
下の【作業の一覧】を、【4つの質問】に上から順に答えて、
「任せる／下書きまで任せる／人がやる」の3つに分けてください。

【4つの質問】
1. 「まとめる」作業か、「決める」作業か
   → 決める作業は「人がやる」
2. 材料は文字やデータでそろっていて、AIに渡してよい情報か
   → そろっていない、または名前や連絡先を消すと成り立たないなら「人がやる」
3. 間違えても、すぐ直せるか
   → 社外に出る、お金や契約に関わるなど、直しにくいなら「下書きまで任せる」
4. 毎回ほぼ同じ形の作業か
   → 毎回ちがうなら「下書きまで任せる」
4つとも通った作業だけ「任せる」にしてください。

【出し方】
- 表で出す。列は「作業／分け方／どの質問で決まったか／人が確かめること」
- 情報が足りなくて分けられない作業は、勝手に決めずに、
  最後に「確認したいこと」として質問を並べる
- ツールやサービスの名前は出さない

【作業の一覧】
（ここに、1週間でやっている作業を1行ずつ書く。
　お客様の名前・社員の名前・金額は書かない）

AIの出した仕分けは、そのまま会社の決まりにはしません。
これは社内の決まりを作る「決める」作業なので、4つの質問に当てはめると「人がやる」に入ります。
仕分けの表を材料にして、最後は人が決めます。

気をつけること

お客様や社員の情報は、そのまま貼らない

個人情報保護委員会は、生成AI（文章などを作るAI）のサービスを使う事業者に向けて、2つの注意を呼びかけています。
1つ目は、個人情報を含む内容を入力するときは、決めてある利用の目的に必要な範囲に収まっているかを確かめることです。
2つ目は、本人の同意を得ずに個人データ（名簿や表のように、探せる形にまとめた個人情報）を入力するときは、サービスを提供する会社がそのデータをAIの学習（AIの性能を上げるための材料にすること）に使わないことなどを確かめることです。
入力したデータが、答えを出す以外の目的で使われると、個人情報保護法に違反する可能性があるためです（参考にしたもの①）。

実際の作業では、名前を「Aさん」に置きかえる、連絡先の列を消してから貼る、などの形にします。
使っているAIのサービスで、入力した内容が学習に使われない設定になっているかも、最初に確かめておきます。

AIは、それらしい間違いを書くことがある

AIは、渡していない事実を、もっともらしく書いてしまうことがあります。
数字・日付・人や会社の名前は、元の資料と見比べます。

「任せる」作業も、最初の数回は全部見る

「任せる」に分けた作業でも、はじめの数回は出てきたものを全部読みます。
指示文が安定してから、ときどき見る形に切りかえます。

責任は、人に残る

AIが作ったものでも、それを使った結果は、AIではなく、使った会社の側が引き受けることになります。
「だれが最後に確かめるか」を、作業ごとに1人決めておくと、確かめ忘れが起きにくくなります。

どこから始めるか

一度に全部を仕分ける必要はありません。
始めやすい順番は、次のとおりです。

  1. 自分の作業を1週間分、書き出す
  2. 上の指示文で3つに分ける
  3. 「下書きまで任せる」の中から、回数がいちばん多い作業を1つ選ぶ
  4. その作業だけ、2週間続けてみる

「任せる」ではなく「下書きまで任せる」から始めるのは、人が必ず読むので、間違いが外に出にくいからです。
どれくらい時間が減るかは、作業の中身と回数で変わります。
始める前に、その作業に1回何分かかっているかを書いておくと、続けるかどうかを数字で決められます。

まとめ

  1. AIに任せる仕事は、「まとめるか決めるか」「材料がそろっていて渡せるか」「すぐ直せるか」「毎回同じ形か」の4つの質問で決められます
  2. 分け方は2つではなく、「任せる・下書きまで任せる・人がやる」の3つにします
  3. 始めるのは、「下書きまで任せる」の中で回数がいちばん多い作業を1つからで十分です
