提出物のリマインドメール例文｜社内・お客様への依頼をAIで下書き

2026年10月18日

社内のスタッフや、お客様・取引先に、書類やアンケート、申込書の提出をお願いしている人は、出し忘れている相手に、提出物のリマインドメールを1通ずつ書いているのではないでしょうか。
例文は探せば見つかりますが、本当に時間がかかるのは「だれがまだ出していないかを確かめる」ことと、「責めているように聞こえない言い方を、相手ごとに考える」ことです。

この記事では、未提出の相手だけを表で拾い、リマインドメールの下書きをAIに人数分作ってもらう手順を紹介します。
結論から言うと、「一覧に提出日を入れる → 未提出の相手を表で拾う → AIに責めない言い方で下書きを出してもらう → 見直して自分で送る」の4段です。

指示文（プロンプト）は、期限の前・当日・過ぎたあとの3つの場面に使える形で、全文を載せています。

こんな作業に、時間を取られていませんか

たとえば、月末までに、お客様から必要書類を、社内のスタッフから月の報告を、あわせて12人分集める人の例です。

  • 締め切りの2日前になっても、4人がまだ出していない
  • 催促のメールは、「忙しい人」「いつも早い人」「前回も遅れた人」で、言い方を変えたくなる

1通は短くても、4人分を毎回やると、目安で20〜35分ほどかかります（測った数字ではありません）。
しかも、もう出した相手に送ってしまうと、気まずくなります。

結論：提出物のリマインドは「拾う・下書き・見直し・送る」で減らせます

全体の流れは次の4段です。

段やることだれがやるかかかる時間（目安）
1提出状況の一覧を用意する（形を決めるのは最初の1回だけ）自分初回15分、2回目からは更新だけ
2未提出の相手だけを、表のフィルター（条件に合う行だけを表示する機能）で拾う表の機能1〜2分
3未提出の相手の分だけ、リマインドの下書きを出してもらうAI2〜3分
4見直して、自分のメールから送る自分1通1分ほど

ポイントは2つです。

ひとつは、だれが未提出かをAIに判断させないことです。
一覧とフィルターで拾うほうが、見落としが少なくなります。

もうひとつは、責めない言い方の「決まり」を、指示文に書いておくことです。
毎回その場で言葉を選ぶかわりに、「忘れていると決めつけない」「いつまでなら受け取れるかを書く」といった決まりをAIに渡しておくと、どの相手にも同じ温度で送れます。

手順

ここでは、エクセルかGoogleスプレッドシート（Googleの表計算のサービス）と、ChatGPT や Claude などの対話型のAI（文章で頼むと文章で答えてくれるAI）を使う例で説明します。

ステップ1：提出状況の一覧を用意する

提出物ごとに、次のような一覧を1枚作ります。
すでに名簿があれば、列を足すだけで使えます。

呼び名関係連絡のしかた提出した日メモ
Aさん社内メール10/8
Bさん社内メール
Cさんお客様メール仕事が繁忙期
Dさんお客様メール10/9
Eさん取引先メール前回も遅れ気味

「呼び名」は、本名ではなく、自分で決めた記号やニックネームでかまいません。
「関係」は、社内・お客様・取引先のように、言い方を変えるための列です。
「メモ」には、事情があって今回は待ったほうがよい相手や、言い方に気をつけたい相手のことを、短く書いておきます。

提出を受け取ったら、その場で「提出した日」を入れます。
ここが、この手順でいちばん大事なところです。

ステップ2：未提出の相手だけを拾う

一覧の見出しの行を選び、エクセルなら「データ」の「フィルター」、Googleスプレッドシートなら「データ」の「フィルタを作成」を選びます。
「提出した日」の列に出るボタン（エクセルは矢印、Googleスプレッドシートはフィルタのアイコン）を押し、エクセルなら「(空白セル)」、Googleスプレッドシートなら「値でフィルタ」の空白の項目だけにチェックを入れると、まだ出していない相手だけが残ります（画面の表示は変わることがあります）。

残った行のうち、メモに事情がある相手は、今回送るかどうかを自分で決めます。
送る相手の「呼び名」から「メモ」までの列を、次のステップで使います。

ステップ3：責めない言い方で、下書きを出してもらう

次の指示文をAIに貼り、（　）を埋めます。
一覧は、表からコピーしてそのまま貼れます。

あなたは、仕事のメールを手伝うアシスタントです。
下の「提出のお願いの内容」と「未提出の相手の一覧」をもとに、提出物のリマインドメールの下書きを、一覧の人数分作ってください。

条件：
- 1人につき1通、件名と本文を作ってください
- 件名には、提出物の名前と期限を入れてください（例：【ご確認】月末提出の書類（10/12 21時まで））
- 今の場面は「（期限の前／期限の当日／期限を過ぎた）」です。場面に合わせて、次のように書いてください
  ・期限の前：念のためのお知らせとして、短く書く
  ・期限の当日：今日が期限であることを、はっきり書く
  ・期限を過ぎた：いつまでなら受け取れるかを書く。受け取れる日がないときは、その旨を書く
- 「関係」に合わせて言い方を変えてください
  ・社内：用件を短く、かしこまりすぎない
  ・お客様・取引先：ていねいに。「お忙しいところ恐縮ですが」などのひと言を入れる
- 責める言い方は使わないでください。「まだ出ていません」「遅れています」「なぜ出していないのですか」は書かず、「ご確認のお願い」として書いてください
- 相手が忘れていると決めつけないでください。「行き違いでしたら、ご容赦ください」の1文を入れてください
- 「難しい事情があれば、お知らせください」の1文を入れてください
- 提出方法を1〜2行で書いてください
- 下の内容に書かれていないこと（理由、ほかの相手の提出状況、契約や料金への影響、罰則など）は、書かないでください
- 「メモ」に書かれたことは、本文にそのまま書かないでください。言い方を選ぶためだけに使ってください
- 宛名は「（呼び名）さん」のまま入れてください。自分が送る前に本名に直します
- 文字数は、本文で200〜300字にしてください

【提出のお願いの内容】
- 用件：（例：月末の締めの準備）
- 提出物：（例：必要書類、月の報告）
- 期限：（例：10月12日（月）21時）
- 期限を過ぎた場合に受け取れる日：（例：10月14日（水）まで）
- 出し方：（例：このメールに返信して、ファイルを添付する）
- 差出人の名前：（例：〇〇）

【未提出の相手の一覧】
（呼び名・関係・連絡のしかた・メモの列を貼る）

たとえば、場面が「期限を過ぎた」で、関係が「お客様」で、メモが「仕事が繁忙期」のCさんに向けた下書きは、次のような形になります。

件名：【ご確認】必要書類について（10/14まで受け付けています）

Cさん

こんにちは。〇〇の△△です。
月末の準備に必要な書類について、ご確認のご連絡です。
10月14日（水）までは、このメールに返信してファイルを添付していただければ、お受け取りできます。
行き違いでご提出済みでしたら、ご容赦ください。
難しい事情があれば、いつでもお知らせください。

〇〇

同じ一覧で、場面を「期限の前」に変えれば、次の回の下書きもすぐに出せます。

ステップ4：見直して、自分で送る

下書きを、次の表で見直します。

見るところ見る内容
宛先送る直前に一覧を見直し、提出済みになった相手を外したか
宛名「Cさん」を、いつも使っている呼び方に直したか。宛名と本文の名前が合っているか
期限・出し方日付・曜日・時間・提出方法が、お願いの内容と同じか
事情メモに書いた事情が、本文にそのまま出ていないか
言い方「遅れている」と責めるように読めるところがないか。自分がいつも使う言い方と合っているか

送るのは、自分のメールから行います。
下書きに間違いがあったとき、送る前に止められるのは自分だけだからです。

気をつけること

相手の情報は、必要なところだけをAIに渡す

お客様やスタッフの名前や連絡先は、大切な預かりものです。
AIに貼るのは、呼び名・関係・連絡のしかた・短いメモだけにします。
本名、メールアドレス、電話番号、住所、契約の内容、金額、体調やご家庭のことは貼りません。
「メモ」には、「繁忙期」「前回も遅れ気味」くらいの短い言葉だけを書きます。

社内のスタッフ向けに絞った手順は、提出の催促メール、未提出の一覧からAIで下書きを作る手順（社内向け）にまとめています。

AIに任せないこと

  • だれが未提出かの判断：一覧とフィルターで拾います
  • 送るかどうか、待つかどうか：事情がありそうな相手に今送るかは、自分で決めます
  • 送信：自分で読んで、自分で送ります

何度も遅れる相手が多いときは、出し方のほうを見直す

同じ相手が毎回遅れるときや、毎回何人も遅れるときは、文面より、提出のしかたに原因があることがあります。
たとえば、提出先が2か所に分かれている、期限が依頼ごとにばらばら、出し方の説明が最初の案内にしかない、などです。期限を毎回同じ曜日と時間にするだけでも変わります。

どれくらい減るか

目安ですが、12人に提出をお願いして、そのうち4人にリマインドする場合は、次のくらいになります（測った数字ではありません）。

手でやる場合この手順の場合
未提出の相手を確かめる5〜10分（届いたメールを見返す）1〜2分（フィルターで拾う）
4通のメールを書く15〜25分（言葉選びを含む）5〜8分（下書きを出す3分＋見直して送る3〜5分ほど）
期限を過ぎたあとの2回目もう一度、1通ずつ書く場面を変えて頼み直すだけ

いちばん減るのは、「だれに送るか確かめる時間」と「言葉を選び直す時間」です。
ただし、提出を受け取ったときに一覧へ日付を入れる手間は、新しく増えます。

まとめ

  1. 提出状況の一覧を作り、受け取ったらその場で提出した日を入れる
  2. 未提出の相手は表のフィルターで拾い、AIには呼び名・関係・連絡のしかた・短いメモだけを渡して、責めない言い方の下書きを出してもらう
  3. AIに任せるのは下書きまで。送る直前に一覧を見直し、自分で送る
